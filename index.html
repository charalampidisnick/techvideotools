FAQ

Questions

Do I need internet at the venue?

No. Activation and the timer work completely offline. Phones, tablets, browser outputs and Stream Deck only need the same local network as the timer computer.

Can I use one licence on two computers?

Each key is made for one computer's Machine ID. For a main and a backup machine, request two keys in the same form.

Does it work with Stream Deck?

Yes, through the free Bitfocus Companion. Every function — play, ± time, presets, messages, black, views — has a simple command. The full list is in the manual.

Which NDI receivers work?

Any NDI receiver on the network: vMix, TriCaster, OBS with the NDI plugin, NDI Studio Monitor and hardware decoders. The source is sent at 1920×1080, 30 fps.

macOS says the app can't be opened.

The first time, right-click Show Timer in Applications → Open → Open. If it still refuses, open System Settings → Privacy & Security and click “Open Anyway”.

Windows shows “Windows protected your PC”.

Click “More info” → “Run anyway”. This appears for new apps that are not yet widely downloaded.
